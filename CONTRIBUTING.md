# Contributing

Thanks for helping improve this Automata Theory & Computation learning repository.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Keep changes relevant to the course, implementations, tests, or documentation.
3. Add or update automated tests when behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Run `ruff check .` when Ruff is installed.
6. Update the README or relevant documentation when commands or behavior change.

## Code style

- Prefer clear names and small functions.
- Keep examples beginner-friendly and explain non-obvious automata/parser logic.
- Avoid unnecessary third-party dependencies.
- Do not commit generated caches, local IDE state, credentials, or personal data.

## Pull requests

Describe the motivation, summarize the changes, list the tests run, and mention any known limitations. Keep each pull request reviewable and avoid unrelated formatting changes.
